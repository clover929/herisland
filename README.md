# HerSpace
成年女性交流互助社区，本地演示版本。

启动：`npm install --cache .npm-cache` 后 `npm run dev`，访问 http://127.0.0.1:3000。

检查：`npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`。

所有帖子、人物与账户均为演示。收藏、评论、加入社群与新帖子仅存于当前浏览器 localStorage；无真实认证、安全存储或服务器数据库。请勿输入隐私信息。登录注册仅为 UI。清除站点数据可重置。浏览器禁止存储或数据损坏时显示错误提示。

目录：src/app 路由；src/components 界面；src/features 本地状态；src/data 示例；src/lib 筛选；src/types 类型；tests 测试；docs 开发清单。

小晴 Sunny：复制 `.env.example` 为 `.env.local`，确认本机 `ollama serve` 及手动下载 `ollama pull qwen3:4b` 后，运行 `npm run dev`，访问 `/ai`。所有模型请求经 `/api/ai/chat`，无云端回退。保持 Ollama 仅监听回环地址，不开放11434端口。

当前使用稳定非流式回复（统一JSON错误与现有客户端架构），90秒超时，可取消、清空、重试；每条4000字、16条历史、总16000字、请求64KB。开发限流为单进程全局每分钟20次；生产需共享限流及身份/权限方案。取消浏览器请求会向上游传递取消信号，模型释放资源由Ollama决定。聊天不写服务器日志、不持久化，不读取私聊，不执行社区操作。模型回复以React纯文本显示。本地运行不等于正式上线后的端到端隐私保证。

人物库现有102位（10位已发布、92位待内容审核），Explore仅使用10位公开记录的事实与来源；后续按审核发布状态自动扩展，不公开未审核故事。社区示例昵称与故事为虚构，人物资料有真实来源。AI仍可能产生错误，来源需要人工核对。

Explore 检索：`src/features/women/search.ts` 独立执行公开状态过滤、中文/英文姓名、职业、领域、关键词与正文检索及跨领域排序。不需要向量数据库。当前102位已核实记录中仅10位已审核发布可提供给模型。模型仅选择事实编号，服务端使用白名单原始事实和逐项来源生成回答，拒绝模型自由添加事实；无匹配不调用模型。无效编号回退到检索原始事实摘录并明确提示。人物链接与来源以安全链接显示。当前采用词项匹配和少量领域同义词，不支持完整语义理解或代词追问；来源映射经过测试，本轮未重新联网复核外部来源正文。

小晴人格：服务端 `src/features/ai/sunny-persona.ts` 统一管理核心身份、成熟自然的中文表达、适度幽默、独立判断及敏感场景边界。Companion侧重交流与梳理，Explore侧重公开事实与引用，Write侧重用户原有风格与草稿；核心提示词不进入前端。用户只能提交交替的user/assistant消息，不能提交system角色。提示词层级不等于模型绝对服从保证。明显推理草稿由服务端返回可重试错误，不作为最终回答显示；该检测是启发式，不能覆盖所有异常输出。

`tests/sunny-dialogues.ts` 提供15组场景及人工质量检查标准；单测验证服务端规则、模式与历史传递，不把Mock当成自然语言质量证明。`python3 scripts/check-sunny-local.py` 可经本地Next API实测现有Ollama模型；输出为合成测试对话。qwen3:4b实测仍有推理草稿、偏卖萌及格式遵循问题，尚未达到稳定人格质量，未改模型或连接配置。

小晴太阳是纯前端配置：初次客户端随机，25秒非重复轮换，document.hidden时不轮换；关闭状态保存在本标签页sessionStorage，返回/刷新后不自动出现。减少动效关闭浮动与眨眼；点击进入原/ai。

今日岛主按 Asia/Shanghai（UTC+8）自然日，从按slug排序的公开人物池，以日期天数模人数选择。当前10位已发布记录保持不变时10天内不重复；所有用户同日相同。首次值在服务端生成传给客户端，避免hydration随机；页面可见时每分钟检查跨日，NPC随跨日重新排除新岛主。公开池变化会改变当日排位，正式内容发布需考虑冻结按日名单。6位随机NPC来自其余公开人物，支持islandSeed复现；不使用未公开92位资料。主题文案明确非本人原话，事实附来源。
