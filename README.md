# HerSpace
成年女性交流互助社区，本地演示版本。

启动：`npm install --cache .npm-cache` 后 `npm run dev`，访问 http://127.0.0.1:3000。

检查：`npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`。

所有帖子、人物与账户均为演示。收藏、评论、加入社群与新帖子仅存于当前浏览器 localStorage；无真实认证、安全存储或服务器数据库。请勿输入隐私信息。登录注册仅为 UI。清除站点数据可重置。浏览器禁止存储或数据损坏时显示错误提示。

目录：src/app 路由；src/components 界面；src/features 本地状态；src/data 示例；src/lib 筛选；src/types 类型；tests 测试；docs 开发清单。
