## 当前真实状态

- 项目目录 `/Users/cloverwu/Projects/her-community`，已有 Next.js 16.4.5、React 19.3.1、严格 TypeScript、Tailwind、Lucide、ESLint、Vitest、Playwright。
- `src/app/[[...slug]]/page.tsx` 是统一路由入口，将路径交给大型客户端组件 `src/components/community-app.tsx` 条件渲染；不是各页面独立路由模块。布局与全局样式位于 src/app。
- 首页、讨论列表/详情、发布页、社群列表/详情、个人页、登录/注册、故事详情均有界面。导航、搜索、分类、本地发帖/评论/收藏/加入退出可交互。
- `src/data/index.ts` 有 16 个不同标题帖子、8 分类、6 社群、4 故事标题。帖子共用正文，故事详情共用同一个虚构人物正文；不等于完成了四篇独立人物专题。
- 热门话题按钮实际上筛选分类；最新动态、社群成员、活动与规则为静态示例。社群讨论按分类关联，无真正社群归属。
- 评论回复只聚焦输入框并预填 @慢慢来，无父评论关系、通知或回复树。
- 本地状态见 `src/features/store.ts`：localStorage 键 `herspace-demo`，保存 posts、saved、joined、comments；没有服务端数据库、API、账号隔离或跨设备同步。
- Post 只有字符串 id/title/content/category/author/mode；Comment 只有 postId/text。缺少稳定用户 ID、时间、社群 ID、评论 ID、权限与审核状态。
- 登录注册仅原型，提交显示提示；不认证、不保存账号。成年确认不构成年龄验证。个人资料固定为演示身份。
- 举报、活动报名、隐私设置、公寓仅提示即将推出。头像编辑、真正用户资料编辑、内容编辑删除、审核、通知均未实现。
- 空结果与存储异常有提示；未知路径显示页面不存在，但统一路由未调用 notFound，不能视为正确 HTTP 404。初始存储读取前仍可交互，有覆盖持久化数据的竞态风险。
- parseState 校验基础形状，未校验分类/模式枚举、长度、关联完整性与版本；没有跨标签同步或迁移策略。
- Git main 尚无提交，git ls-files 为空，源码与配置均为未跟踪文件。本轮不自动提交。
